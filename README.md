# ⚔️ فارس الأبعاد | Cosmic Knight 2D
### **لعبة مغامرات ومنصات 2D حماسية متعددة المراحل ومتوافقة مع الكمبيوتر والموبايل**
> **برمجة وتطوير: أحمد عبد الوهاب (Ahmed Abdelwahab)**

---

## 🌟 نظرة عامة (Overview)
**فارس الأبعاد (Cosmic Knight 2D)** هي لعبة مغامرات ومنصات كلاسيكية مبنية بأحدث تقنيات الويب (HTML5 Canvas & Vanilla JavaScript) بدون أي مكتبات خارجية، مع نظام تحكم لمسي يحاكي منصات الكونسول الاحترافية، وتأثيرات صوتية ديناميكية مبنية بالكامل عبر Web Audio API Synth.

---

## 🎮 مميزات اللعبة الرئيسية:

### 1. عوالم ومراحل متعددة (6 Handcrafted Stages & Biomes):
- 🌲 **المرحلة 1: الغابة الساحرة (Enchanted Forest)** - تعريف بالآليات والقفز بين الأشجار.
- 💎 **المرحلة 2: الكهف الكريستالي (Crystal Cavern)** - منصات منهارة وقفزات جدارية دقيقة.
- 🌋 **المرحلة 3: الجحيم البركاني (Volcano Core)** - بحار الحمم الحارقة والمنصات المتحركة.
- ☁️ **المرحلة 4: أطلال السماء (Ancient Sky Ruins)** - منصات ارتدادية وقفزات هوائية عملاقة.
- ⚡ **المرحلة 5: المختبر السيبراني (Cybernetics Lab)** - بوابات ليزرية ودفاعات ذكية.
- 👑 **المرحلة 6: عرين العملاق الأخير (The Cyber Colossus)** - معركة زعيم ملحمية بـ 3 أطوار هجومية (ليزر مزدوج، نيازك ساقطة، وانتقال آني خاطف).

### 2. تحكم كونسول احترافي للهاتف (Console Grade Mobile Controls):
- 🕹️ **عصا تحكم تناظرية 4-Way (Pro Virtual Analog Joystick)**:
  - ⬆️ **سحب لأعلى**: قفز وقفز مزدوج سلس.
  - ⬇️ **سحب لأسفل**: انحناء ونزول من المنصات.
  - ⬅️ ➡️ **سحب يميناً ويساراً**: حركة رشيقة مع مؤشرات LED متوهجة.
- ⚔️ **زر هجوم السيف الياقوتي (ATTACK)**: ضربات سريعة متتابعة مع إمكانية **صد وتدمير قذائف الأعداء**.
- ⚡ **زر الاندفاع الذهبي (DASH)**: اختراق الحواجز والأعداء وتفادي هجمات الزعيم بحصانة مؤقتة.
- 📱↔️ **قفل إجباري للوضع الأفقي (Mandatory Landscape Mode)** لضمان شاشة عريضة وتجربة لعب مريحة.

### 3. المتجر والتطوير (Shop & Customization):
- 🎭 **أزياء الفارس**: الفارس الكوني، النينجا السيبراني، وفارس الحمم.
- ✨ **هالات الاندفاع (Dash Trails)**: أزرق نيون، لهب بركاني، وبرق بنفسجي.
- 🛡️ **ترقيات دائمة**: زيادة القلوب والسرعة وحفظ التقدم تلقائياً عبر `localStorage`.

### 4. محرك صوت وجزيئات ديناميكي (Web Audio Synth & Particles):
- لا تعتمد على ملفات صوت خارجية؛ تُولّد جميع النغمات والمؤثرات الصوتية في الوقت الفعلي عبر الـ Web Audio API Synth.
- مؤثرات بصرية متقدمة للغبار، شرارات الضربات، وميض السيف، انفجارات الأعداء، واحتفالات الفوز.

## 🕹️ أزرار التحكم (Controls):

### للكمبيوتر واللابتوب (Desktop):
| الزر | الوظيفة |
|---|---|
| `A` / `D` أو `⬅️` `➡️` | الحركة يميناً ويساراً |
| `W` / `Space` أو `⬆️` | القفز (اضغط مرتين للقفز المزدوج) |
| `S` أو `⬇️` | الانحناء / النزول من المنصات |
| `J` / `Z` أو `كليك الماوس اليسار` | الهجوم بالسيف وصد القذائف |
| `K` / `Shift` | اندفاع سريع (Dash) |
| `Esc` / `P` | إيقاف اللعبة مؤقتاً |

### للهواتف والأجهزة اللوحية (Mobile):
- **في اليسار**: عصا الـ Joystick التناظرية للحركة والقفز والانحناء.
- **في اليمين**: زر السيف (ATTACK) وزر الاندفاع (DASH).

## 🚀 طريقة التشغيل محلياً (Run Locally):

1. **استنساخ المشروع (Clone Repo)**:
   ```bash
   git clone https://github.com/USERNAME/cosmic-knight-2d.git
   cd cosmic-knight-2d
   ```

2. **تشغيل خادم محلي (Local Server)**:
   ```bash
   # باستخدام Python:
   python -m http.server 3000

   # أو باستخدام Node (npx serve):
   npx serve .
   ```

3. **افتح المتصفح على**:
   - `http://localhost:3000`

---

## 🌐 النشر على GitHub Pages:
1. ارفع المشروع إلى مستودع جديد على GitHub.
2. اذهب إلى **Settings** > **Pages**.
3. اختر الفرع `main` والمجلد `/ (root)` ثم اضغط **Save**.
4. ستعمل اللعبة فوراً كـ Web App جاهز للعب من أي جهاز حول العالم!
